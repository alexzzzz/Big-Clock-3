# ADR-0001: Stack для Big Clock — .NET for Android (C#)

- **Статус:** Accepted (2026-08-23) — закрывает #3, базируется на research #2 (`research/stack-choice` ветка). **Актуализировано 2026-08-24:** фактическая сборка на `net11.0-android` (workload 37) — совместимо, см. примечание ниже.
- **Контекст:** Автор привык к .NET, приложение — один экран `ЧЧ:ММ` с мигающим `:`, принудительный ландшафт, immersive, keepScreenOn. Рассматривались Kotlin+Compose (2–4 MB APK, native) vs .NET for Android (`net11.0-android`, 10–18 MB, C#) vs .NET MAUI (15–25 MB, overkill).
- **Решение:** **.NET for Android** (`TargetFramework net11.0-android`, C# 12/13, `Sdk="Microsoft.NET.Sdk"`). Один `Activity` (`BigClockActivity`), layout `Resources/layout/activity_big_clock.xml` с `clockText` (`88 88` + `ScaleXSpan 0.5` пробел) и overlay `colonText` (`:`) для мигания через `Alpha`. Fallback Kotlin — отвергнут, MAUI — отвергнут (нет iOS-плана).
- **Границы SDK:** `minSdk 26` (Android 8.0, API 26 — `WindowInsetsControllerCompat` без фолбэка, охват ~97%), `targetSdk 35` (фактически `compileSdk` 37 через workload 37), `applicationId com.alexzzzz.bigclock`, `versionCode 1`, `versionName 1.0.0`.
- **Toolchain:** .NET 11 preview SDK 11.0.100-preview.6 + workload `android` 37.0.0-preview.6.59 (`dotnet workload install android`), JDK 21 LTS (`Android/jdk`), Android SDK 37 (`build-tools 36.0.0`), сборка `dotnet build BigClock3.sln -c Release` → `com.alexzzzz.bigclock-Signed.apk` (19–20 MB), подпись `apksigner`. IDE — Visual Studio 17 (`BigClock3.sln`) / Rider; Gradle/Studio не требуется.
- **Ключевые API:** `AndroidManifest.xml` → `android:screenOrientation="sensorLandscape"`, `android:keepScreenOn` в layout+`Window.AddFlags`; `WindowCompat.setDecorFitsSystemWindows(window, false)` + `WindowInsetsControllerCompat` для immersive + `ShortEdges` для вырезов; `Handler(Looper.MainLooper)` + `postAtTime` выровнен к следующей секунде для мигания `:` (500 мс, `colonText.Alpha`); `Resources/font/digital_7_mono.ttf` (`@font/digital_7_mono`), ручной подбор размера по `TextPaint` (`88 88` с 50% пробелом) в `BigClockActivity.MaximizeClockTextSize`.
- **Последствия:** APK больше чем native (~10–18 MB vs 2–4 MB), но без изучения Kotlin и в привычной экосистеме; тикеты #4–#6 реализованы под .NET API; MAUI не тянем, при необходимости iOS — отдельный ADR. Фактический `net11` сохраняет совместимость с `net10` — код без изменений, кроме `Sdk` и `TargetFramework`.
- **Альтернативы отвергнуты:** Kotlin+Compose — минимальный APK, но требует Kotlin/Studio, автор предпочёл C#; MAUI — избыточен для одного экрана.
