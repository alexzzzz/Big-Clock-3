# CONTEXT — Big Clock

## Glossary

- **Big Clock (Часы)** — Android-приложение, один экран, полноэкранные цифровые часы ЧЧ:ММ с мигающим `:`.
- **Display (Отображение)** — строка ЧЧ:ММ, где ЧЧ и ММ — двузначные, `:` — отдельный элемент, мигает 500 мс вкл / 500 мс выкл, синхронизировано к системной секунде.
- **Fullscreen (Полный экран)** — immersive режим, системные status/nav панели скрыты, `keepScreenOn=true`, принудительный `sensorLandscape`.
- **Tick (Тик)** — обновление дисплея: ЧЧ:ММ — раз в минуту, `:` — раз в 500 мс, выравнивание к началу секунды.

## Context Map

Single-context — один bounded context (отображение времени), без доменных sub-модулей.
